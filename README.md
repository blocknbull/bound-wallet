# Bound Wallet

A policy-enforced smart wallet for AI agents on NEAR. The owner sets limits a
contract enforces; the agent gets a key that can only call one method; every
decision lands on chain.

Building in public at the NEAR Hackathon, 1–14 November 2026. The code lands
when the window opens.
